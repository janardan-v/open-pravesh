# Open-Pravesh
— A Production-Inspired OIDC Identity Provider

A from-scratch authentication and authorization platform implementing **OAuth 2.1** and **OpenID Connect**, built to deeply understand how modern identity providers work under the hood — conceptually similar to a simplified Auth0 or Keycloak.

## Status

🚧 **Planning Phase** — this project is currently being designed. No implementation code has been written yet.

Development will begin soon, and progress (architecture, code, and docs) will be added incrementally as the project moves forward.

## Planned Tech Stack

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Prisma ORM
- Redis
- JWT
- OAuth 2.1
- OpenID Connect

## Basic Goals

- Implement core OAuth 2.1 authorization grant flows
- Implement OpenID Connect discovery, ID tokens, and userinfo endpoints
- Build a working, simplified Identity Provider end-to-end
- Use this project as a deep, hands-on study of authentication/authorization internals
